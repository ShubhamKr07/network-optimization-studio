# docs-audit — week 2026-39

Sweep of the current in-scope doc set. Mechanical layer (`pnpm docs:audit --full`) found **178**
candidates (`stale_reference` 118, `conflicting_instruction` 42, `superseded` 13, `orphan` 1) —
up sharply from 2026-37's 125, mostly because the mechanical detectors don't understand markdown
glob/brace/placeholder syntax or historical progress-log prose, and this repo's `CLAUDE.md` has
grown into a very large dated narrative log since that baseline. Every candidate below was checked
against real code/git (`grep`, `find`, `git log -S`/`--follow`) before being classified — none were
verified only against other docs. 2 real findings survived judgment and were fixed (2 commits,
folding in one detector-duplicate). 175 were dismissed as false positives, grouped into 9 clusters
by shared root cause so the reasoning is auditable without re-litigating each of the 175
individually (a representative sample of each cluster's evidence was hand-verified; ids follow the
verified pattern exactly — see each cluster's rests-on note). 1 is carried over pending a product
decision.

### Cluster: glob/brace/placeholder syntax not expanded (31 ids, `stale_reference`)
The `referenced path does not exist` detector checks the literal string it finds in backticks
against the filesystem. It doesn't expand brace lists (`{routes,services}`), angle-bracket template
placeholders (`<model-id>`), `*` wildcards, or strip a trailing `/**` glob suffix — so a **correct**
path written as a glob for readability (a normal convention in these docs) always "fails to exist"
as a literal string. Verified for representative samples: `artifacts/api-server/src/{routes,
services,validation,registry}/**` (`.claude/agents/backend-engineer.md:11`, id `cb8dd79643`) —
all four of `routes/`, `services/`, `validation/`, `registry/` exist under
`artifacts/api-server/src/`; `lib/db/**` (`d2064bdaf8`), `lib/api-spec/**` (`8acd2d669f`),
`scripts/src/**` (`bf82ebec6f`) all exist as real top-level dirs; `solvers/<model>/manifest.json`
(`.claude/agents/solver-engineer.md:11`, id `e2540748c6`) is the per-model manifest pattern
documented (and used identically) throughout `model-integration-precheck.md`.
