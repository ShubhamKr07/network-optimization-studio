# Product Insights — weekly report

`.github/workflows/product-insights.yml` runs every Monday (and on manual
`workflow_dispatch`) in two steps: `scripts/product-insights/run.ts` queries
PostHog for the past week's aggregates and writes them to
`docs/product-insights/aggregates.json` (a transient build artifact, not
committed — see `.gitignore`); then the `anthropics/claude-code-action@v1`
step reads that file and writes the final markdown recommendations report to
`docs/product-insights/<date>.md`, which the workflow commits.

The synthesis step authenticates via a **Claude Max subscription OAuth
token**, not an Anthropic API key — this repo's LLM usage for this job rides
the user's existing Max plan rather than API billing.

## Required GitHub secrets

Set these in GitHub → Settings → Secrets and variables → Actions → Repository
secrets **before the first scheduled run** (Monday 13:00 UTC) or before
triggering the workflow manually:

- `POSTHOG_PROJECT_KEY`
- `POSTHOG_PERSONAL_API_KEY` — **distinct from the ingest key** (`VITE_POSTHOG_KEY`
  / `POSTHOG_API_KEY`). The HogQL query API used by this script requires a
  *personal* API key, not the public/project ingest key used for capturing
  events.
- `CLAUDE_CODE_OAUTH_TOKEN` — generated by running `claude setup-token` on a
  machine logged into the Claude Max account that should pay for this job's
  synthesis calls. Not an `ANTHROPIC_API_KEY` — this workflow does not use
  API billing at all.

If any of these is missing, the workflow's query or synthesis step fails and
no report is committed — it does not silently no-op.
