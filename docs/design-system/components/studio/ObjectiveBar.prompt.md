Model-summary bar above the workspace: chapter kicker, serif model title, scenario name, and mono stat pills. No targets, no hit/miss coloring.

```jsx
<ObjectiveBar kicker="Chapter 3" title="Al's Athletics — P-Median" scenarioName="Baseline"
  description="Facility-location: choose which warehouses to open to minimize weighted distance to customers."
  stats={["objective 2,384,911","avg distance 413 mi","run 0.24s"]} />
```

Also exports StatPill for standalone mono stat chips.
