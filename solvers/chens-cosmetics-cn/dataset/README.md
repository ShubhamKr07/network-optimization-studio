# Chen's Cosmetics (China) dataset

Display-only postal codes on warehouse/customer rows are sourced externally.

Postal codes derived from GeoNames (https://www.geonames.org/), CC-BY 4.0.

27 rows GeoNames could not place use manual reference overrides: Hong Kong and Macau use China Post SAR codes (999077 / 999078); the other 16 mainland cities use their city postal code, each cited in docs/dataset-audit/chens-geocode-provenance.json.
